# Liyana Palliyali — Architecture

Static portfolio site built from the supplied portfolio PDF and portrait frame sequence.

## Preview locally

Serve this folder with any static HTTP server and open its root URL. The site has no build step or package dependencies.

## Publish with GitHub Pages

In the repository settings, enable Pages for the `main` branch and the repository root. Asset paths are relative so they also work from a project subpath.

The optimized hero sequence and extracted portfolio spreads live under `public/`. The original extracted PNG sequence and PDF render scratch files are excluded from Git.
